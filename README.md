# LapTwin

Drop two karting GPS or telemetry files. Compare the tracks. Files never leave the browser.

Ask this answers: [I'm looking for a simple tool that lets you compare two karting laps side by side](https://www.reddit.com/r/Karting/comments/1vn5guj/has_anyone_vibecoded_a_karting_lap_comparison/)

- No account
- No upload
- Cap: 8 MB each
- CSV with lat/lon (and optional speed) or GPX
- No GoPro mux

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```
